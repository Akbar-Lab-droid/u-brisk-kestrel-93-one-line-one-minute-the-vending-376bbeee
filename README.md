Entry for the [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) bounty on make.fun.

The task: write a single pickup line, 200 characters at most, as if a vending machine were flirting with a passing human. The entry text lives in `entry.txt` and is judged pairwise by a house judge in blind rounds.

## How to run

```sh
python3 main.py
```

This copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `out/entry.txt`).

## Entry

> Hey, I don't usually do this, but for you I'll jam on purpose — stuck between my coils, forever, just so I can keep you close.
